# Пробуждение устройств через MikroTik

На вкладке «Инфо» закреплённого устройства доступна кнопка «Разбудить».
На странице аудитории — «Разбудить всё» для всех закреплённых устройств.
Обе команды доступны любому пользователю с доступом к соответствующей аудитории.
Права управления WAN, защита WAN и текущее состояние online не ограничивают WoL.
Во время отправки кнопки блокируются от повторного нажатия.

## Отправка

API gateway получает MAC-адреса из сервиса аудиторий и параметры подключения
маршрутизатора из Inventory. Пароль и адрес REST-интерфейса не передаются в браузер.
Отправку выполняет сам MikroTik командой `POST /rest/tool/wol` с `mac` и `interface`.
Poller и Policy sync в отправке не участвуют.

Интерфейс определяется по `/rest/ip/address`: выбирается действующий интерфейс
наиболее конкретной сети, в которую входит подсеть аудитории. Это сохраняет
правильный VLAN. При отсутствии подходящего интерфейса или неоднозначности
возвращается ошибка; интерфейс маршрута по умолчанию не используется.

В групповой команде одинаковые MAC-адреса отправляются один раз. Максимум четыре
запроса выполняются параллельно. Ошибка одного устройства не прерывает остальные;
пользователь видит число отправленных пакетов и ошибок. Общая отправка после
определения интерфейса ограничена 30 секундами, запрос к MikroTik — 10 секундами.

Ответ подтверждает отправку пакета, а не фактическое включение компьютера.
Состояние устройства по-прежнему обновляет обычный опрос MikroTik.
Для пробуждения компьютер должен поддерживать WoL и иметь его включённым.

## Проверка прав MikroTik

В «Проверке прав» маршрутизатора добавлены:

- чтение IP-адресов и интерфейсов (`GET /rest/ip/address`);
- выполнение WoL (`POST /rest/tool/wol`).

Проверка WoL отправляет служебный пакет с MAC `02:00:00:00:00:00` через один
из действующих IP-интерфейсов. MAC устройств аудитории для этой проверки не используются.
Учётной записи MikroTik нужны права чтения IP-адресов и выполнения команды WoL
через REST; отказ RouterOS отражается в результате проверки и в интерфейсе.

## Применение

Из корня проекта на сервере:

```bash
bash scripts/compose-up.sh cmnc-api-gateway cmnc-web
```

Миграции базы данных не требуются.

Документация MikroTik: [Wake on LAN](https://help.mikrotik.com/docs/spaces/ROS/pages/120782862/Wake+on+LAN),
[REST API](https://help.mikrotik.com/docs/spaces/ROS/pages/47579162/REST+API).
