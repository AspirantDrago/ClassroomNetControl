# Пользователи устройств и история сеансов

Фоновый сбор выполняет `cmnc-veyon-service`, независимо от открытых страниц. Он получает закреплённые устройства активных аудиторий и их доступность из `cmnc-classroom-service`, затем читает `/api/v1/user` через существующую интеграцию Veyon. Приоритет ключей MikroTik/аудитории сохраняется. Не требуется новый доступ к MikroTik или агент Windows.

API Veyon: https://docs.veyon.io/en/latest/developer/webapi.html#user-information

Настройки `.env`:

```dotenv
CMNC_VEYON_USER_POLL_INTERVAL_SECONDS=30
CMNC_VEYON_USER_POLL_CONCURRENCY=2
```

Интервал между циклами — 5–3600 секунд; одновременно опрашиваются 1–8 устройств. Реальный цикл также включает время запросов. Для больших инсталляций можно увеличить параллельность. Новые подключения, созданные только для опроса пользователя, закрываются после чтения; подключения просмотра экрана сохраняются.

Известный логин показывается на вкладке «Инфо». Пустой логин при готовом сеансе отображается как `—`. При выключенном ПК, ошибке связи/ключа, неготовом сеансе или устаревшем наблюдении поле пустое. Данные приходят вместе с API аудитории, отдельные запросы браузера не нужны.

Миграция classroom-service `20261115_0011` создаёт таблицы текущих наблюдений и интервалов. Одинаковые последовательные наблюдения продлевают интервал, смена логина создаёт новый. Срок свежести — максимум из 90 секунд и трёх настроенных интервалов опроса. После истечения срока история остаётся с пропуском; старые сведения не продолжаются бессрочно. Наблюдения для другого IP, MikroTik, аудитории, незакреплённого устройства и неактивной аудитории отбрасываются. Изменения сериализуются блокировкой устройства.

В статистике первая дорожка — пользователи: серый — пользователь отсутствует, бежевый — авторизован, пропуск — нет данных. Подсказка авторизованного интервала содержит логин. Легенда отражает все три состояния. История до установки обновления не восстанавливается.

Обновить только затронутые сервисы:

```bash
bash scripts/compose-up.sh cmnc-classroom-service cmnc-veyon-service cmnc-api-gateway cmnc-web
```

Миграция выполняется при старте classroom-service. Docker Compose использует указанные значения по умолчанию, даже если новые строки ещё не добавлены в серверный `.env`.

Домен в логине скрывается только при отображении (как `DOMAIN\user`, так и `user@domain`); БД и API сохраняют исходную строку. Между интервалами есть видимая граница. При смене двух авторизованных учётных записей без потери свежести время перехода принимается равным последнему успешному наблюдению старого пользователя. Это оценка по опросам, а не точное событие входа. Через устаревшие данные переход не переносится: пропуск сохраняется.

В карточках логин показывается над загруженной миниатюрой, а в описании — последней строкой перед кнопкой Интернета. При отсутствии логина над миниатюрой строка не резервируется, в описании отображается `—`. Длинные подписи обрезаются с троеточием.
