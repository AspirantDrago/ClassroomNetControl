# Активация и удаление аудиторий

Неактивные аудитории показываются перечёркнутыми при включённой настройке их отображения. В форме активной аудитории доступна деактивация, в форме неактивной — активация и окончательное удаление с подтверждением. Обычное сохранение формы не меняет активность.

Окончательное удаление разрешено пользователям с `classrooms:manage` только при отсутствии устройств (включая незакреплённые), камер (включая отключённые) и назначений пользователям или рабочим станциям (включая неактивных). Связанные записи автоматически не удаляются. При отказе причина отображается в форме.

Назначения доступа и удаление координируются сервисом авторизации: транзакционная блокировка сериализует изменения назначений, а миграция `20261113_0004` добавляет устойчивое резервирование удаляемого ID. Сервис аудиторий проверяет токен попытки после блокировки строки аудитории; внешние ключи не позволяют одновременно добавить зависимые записи. Каскадное удаление ORM не используется.

Если результат межсервисного запроса неизвестен, резервирование сохраняется. Повторное удаление получает новый токен; успешная активация снимает резервирование. Недоступность проверки запрещает удаление. Резервирование удалённого ID не позволяет впоследствии назначить его пользователю или станции.

Обновление четырёх сервисов (миграция авторизации выполняется при старте):

```bash
bash scripts/compose-up.sh cmnc-auth-service cmnc-classroom-service cmnc-api-gateway cmnc-web
```

Изменять `.env` для этого обновления не требуется.
