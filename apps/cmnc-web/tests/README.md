# Проверка записи экрана

Тесты используют настоящий MediaRecorder Chromium и подставные кадры.
Реальные устройства и Veyon не вызываются. Нужен установленный Playwright
с Chromium (например, в отдельном каталоге инструментов; путь к модулю можно
передать через `CMNC_PLAYWRIGHT_MODULE`, к браузеру — `CMNC_TEST_CHROMIUM_PATH`).

Из `apps/cmnc-web` запустите тестовый Vite с коротким лимитом:

```bash
VITE_RECORDING_MAX_DURATION_SECONDS=6 npm run dev -- --host 127.0.0.1 --port 5188 --strictPort
```

В другом терминале:

```bash
node tests/recording.browser.cjs
node tests/recording-file-writer.browser.cjs
```

Первый тест проверяет запись на ПК/мобильной ширине, параметры качества,
остановку таймера на паузе, продолжение, воспроизведение полученного WebM,
имя файла, отмену, очистку временных фрагментов и автоматический лимит.
Второй проверяет путь прямой записи в файл с подставным файловым диалогом,
настоящим VP8 вместо VP9, отмену через abort и закрытие файла по лимиту.
Артефакты первого теста пишутся в отдельный временный каталог системы.
